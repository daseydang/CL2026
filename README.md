# CL2026

**Dasey Dang | UW–Madison MS in Psychology: Data Science & Human Behavior**  
**Capstone partner:** Carnegie Learning

This repository documents my analysis workflow for the Carnegie Learning capstone. I’m exploring how students respond to difficulty in digital learning environments and whether their subsequent behaviors relate to recovery and later performance.

The project begins with an exploratory data analysis (EDA) script prepared by my teammate Emily. I’ll document my own data preparation, analyses, decisions, and findings here as the work develops.

## Project Structure

| Path | Description |
| --- | --- |
| `scripts/` | EDA and analysis scripts |
| `docs/` | Research notes and analysis decisions |
| `results/` | Figures and shareable summary outputs |
| `data/` | Local data excluded from Git |

## Data Access

Project data may include student interaction events and other Carnegie Learning research datasets. Access is limited to other
authorized project members. The `data/` directory and common data file formats are excluded by `.gitignore`.

Setup instructions, dependencies, and the order for running scripts will be added as the analysis workflow is established.
